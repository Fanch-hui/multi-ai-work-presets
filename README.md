## 验收与许可

岗位已在 macOS arm64 上使用 Qoder 通道的 Qwen3.8-Max / Qwen3.8-Flash，以及 Antigravity 通道的 Gemini 3.8 Flash 完成代表性模拟资料任务，实际读取绑定技能并交付可审阅成果，包含原始任务和带审阅意见的完整修订验收。各岗位实际模型与摘要见 `presets/readiness.json`。法律岗位按已确认法域和规则辅助整理与审阅，成果供专业人员复核。

每个 ZIP 包含固定上游提交、完整配套资源、LICENSE 和 NOTICE。所有来源仓库核验时至少 200 Star，同时比较岗位匹配、具体内容质量和热度；匹配和质量相近时优先更高 Star，细分岗位按实际能力选择。不同材料按各自许可分发。需计算、绘图和工时校验的岗位声明命令工具与随包运行库依赖，由用户授权。

## 使用与更新

完整职业目录包含作者、工程、行政、采购、客服、项目管理、软件、数据、翻译、制造和物流等分类，需要 multi-AI work 0.6.23 或后续支持扩展分类的版本。更新 App 后，在智能体市场点击“检查更新”，即可按职业浏览、下载和配置岗位。后续同分类内容通过市场更新。

`catalog-v2.json` 提供完整 24 类目录；`catalog.json` 保留原 13 类客户端的兼容目录。每个下载均指向固定 Release 标签并附 SHA256；已有成员的更新由用户手动选择应用，保留个人配置与补充要求。
