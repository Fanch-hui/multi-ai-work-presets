## 验收与许可

岗位已在 macOS arm64、Qoder 通道的 Qwen3.8-Max 或 Qwen3.8-Flash 上完成代表性模拟资料任务，实际读取绑定技能并交付可审阅成果。各岗位实际模型与摘要见 `presets/readiness.json`；其他模型、平台和未覆盖任务需分别验证。法律岗位按已确认法域和规则辅助整理与审阅；成果供专业人员复核。

每个 ZIP 包含固定上游提交、完整配套资源、LICENSE 和 NOTICE。所有来源仓库在核验时至少 200 Star；不同材料按各自许可分发。需计算、绘图和工时校验的岗位显式声明命令工具与随包运行库依赖，使用用户授予的权限。

目录中的 ZIP 指向固定 Release 标签并附 SHA256。已有成员的更新由用户手动选择应用，保留个人配置与补充要求。App 内进入智能体市场，点击“检查更新”，再选择“全部预设”浏览完整目录。
