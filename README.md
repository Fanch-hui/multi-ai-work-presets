## 验收与许可

岗位已在 macOS arm64、Qoder／Qwen3.8-Max 上完成代表性模拟资料任务，实际读取配套技能并交付可审阅成果。其他模型、平台和未覆盖的交付格式需分别验收。预设使用用户明确授予的权限。

每个 ZIP 包含完整资源、固定上游提交以及各技能 LICENSE 和 NOTICE；不同材料适用各自许可。目录中的 ZIP 指向固定 Release 标签并附 SHA256；后续更新由用户手动应用。
