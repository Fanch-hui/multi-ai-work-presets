# multi-AI work 职业预设

multi-AI work 的官方预设分发仓库。智能体市场通过 GitHub Releases 获取目录和固定版本资源包。

## 首批岗位

- 案件接待助理
- 证据整理助理
- 课程辅导助教
- 复习备考教练
- 实习简历顾问

每个岗位包含 3 个技能，共 13 个去重技能。下载 ZIP 后也可通过 App 智能体市场的本地导入入口安装，配置连接、模型和权限后加入团队。

[下载预设](https://github.com/Fanch-hui/multi-ai-work-presets/releases/latest) · [官方目录](https://github.com/Fanch-hui/multi-ai-work-presets/releases/latest/download/catalog.json)

## 版本与验收

首版 1.0.0 已在 macOS arm64、Qoder／Qwen3.8-Max 上完成代表性模拟资料任务，实际读取技能并交付 Markdown 成果。其他模型、平台和额外交付格式尚未完成相同验收。法律岗位用于接待与资料整理，涉及程序及法域的判断须核实适用依据。

目录中每个 ZIP 指向固定 Release 标签，附 SHA256 与大小；安装后由用户手动选择更新。`presets/` 保存对应资源源文件、上游固定提交、核验记录及各技能许可。
