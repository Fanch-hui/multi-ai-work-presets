# multi-AI work 职业预设

官方预设通过 GitHub Releases 分发。当前正式目录含12个岗位，每岗配套3个Skill。

## 可用岗位

- 案件接待助理
- 证据整理助理
- 课程辅导助教
- 复习备考教练
- 实习简历顾问
- 用户研究员
- 竞品分析师
- 需求分析师
- 产品文档专员
- 产品数据分析师
- 产品运营策划
- 产品项目协调员

[下载预设](https://github.com/Fanch-hui/multi-ai-work-presets/releases/latest) · [官方目录](https://github.com/Fanch-hui/multi-ai-work-presets/releases/latest/download/catalog.json)

## 验收与许可

岗位已在macOS arm64、Qoder／Qwen3.8-Max以代表性模拟资料完成真实技能读取和Markdown成果审阅。其他平台、模型和额外交付格式需分别验收。预设仅使用用户明确授予的权限。

每个ZIP包含完整资源、固定上游提交及各技能LICENSE和NOTICE；不同材料适用各自MIT、Apache-2.0或CC BY-SA 4.0许可。目录中的ZIP指向固定Release标签并附SHA256。后续更新由用户手动应用。
